Component overview

LayerWhat it isRole
Offline learning loopTraining module Generator → Reflector → Curator; validation gate on a held-out quarter; persists learned rules on accept.
Learned rulesPersistent rule store + loader Persist rules; load / render / save.
Generator / Reflector / CuratorPrediction engine, miss analysis, merge Scored predictions, miss analysis, proposed and merged rule updates.
Live pathWebhook handler + prediction engine Webhook → prediction per focal asset → submit.
Data providersSEC filings; fundamentals; market prices SEC filings active in the strategy comparison; fundamentals/market prices not wired in.
Scoring / comparisonContest scorer + offline comparison Percentile ranking, delta R², logged over time.
Remote vs local: the Modal-deployed app (right) handles live webhooks and submits predictions to the platform; it runs a summary-only prediction engine using the rules snapshot taken at deploy time. Everything on the left is local: the automated ACE testing loop proposes and persists learned rules, the manual strategy comparison scores candidates offline, and the orange dashed boxes are manual steps (edit rules, run training, run comparison, deploy, commit). The SEC signal is currently active only in the offline strategy comparison.
